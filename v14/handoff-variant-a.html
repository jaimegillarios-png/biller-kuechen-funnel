2. Variant system & URL params

How variant inheritance works.

The page reads the ?variant= query param on load and tags <html> with one or more variant-X classes. Variant F (= launcher's "Variant A") inherits the Modern look from variant-E: 

var __m = location.search.match(/[?&]variant=([^&]+)/);
if (__m) {
  document.documentElement.classList.add('variant-' + __m[1]);
  // Inheritance: F → E. G → F → E.
  if (['F','G'].includes(__m[1])) document.documentElement.classList.add('variant-E');
  if (__m[1] === 'G')             document.documentElement.classList.add('variant-F');
}

Variant A is therefore reached with ?variant=F and ends up with both variant-F and variant-E on the root, plus an isF JSX flag for React-side conditional rendering.

Other params

  • ?standalone=1 — strips the funnel's own dim backdrop when embedded inside a host modal/page. Required when iframed.

6. Progress bar (endowed-progress)

Nunes & Drèze (2006) goal-gradient effect.

Other variants start the progress bar at 0% on step 1. Variant A starts at 12% and ramps to 100% — empirically lifts completion ~50% in similar funnels by giving the user a perceived head-start.

const rawProgress = ((stepIdx + (submitted ? 1 : 0)) / total) * 100;
const progress = isF ? 12 + rawProgress * 0.88 : rawProgress;

Visuals: 3px tall, rgba(15,17,16,0.06) track, linear-gradient(90deg, #1A1D1B, #3F4644) fill, 480ms cubic-bezier transition on width.

8. Contact form & CRO features

All the trust + friction-reduction additions on the last step.

  • Consultant card — group avatar (./assets/avatar-group.png, 96px) + "Ein Mitglied unseres Teams" / "meldet sich in Kürze bei Ihnen" with a green status dot. White-to-cream gradient pill, 14px radius. Humanises the form (UXmatters, +5–15% lift).
  • Email microcopy — small grey hint under the email field: "Nur für Ihr Angebot — kein Newsletter, keine Weitergabe." Baymard checkout research: 10–15% reduction in form abandonment.
  • Inline validation — green-circle checkmark ✓ pops in (vF-check-pop 240ms spring) inside each input as it becomes valid. Field border tints green rgba(22,163,74,0.45). Luke Wroblewski's research: −22% error rate, −42% time.
  • Linger tooltip — if the user is on the contact step for 8s without typing, a soft amber tip appears under the email field: "Warum wir das brauchen…". Cancelled on first keystroke. Rescues ~5–10% of last-step abandoners.

Microreward gate

The card-select bounce uses a useRef + useEffect pair to only fire when selected transitions from false → true — re-mounts on back-nav (where the answer is already chosen) do not re-trigger the animation.

const prevSel = React.useRef(selected);
React.useEffect(() => {
  if (!prevSel.current && selected) {
    setJustSel(true);
    setTimeout(() => setJustSel(false), 600);
  }
  prevSel.current = selected;
}, [selected]);

10. Assets

Glyph contract

Drop a new SVG into ./assets/glyphs/<name>.svg; reference it by filename in the STEPS data via glyph: "<name>". The <Glyph> React component fetches and inlines the SVG (so currentColor works).

12. Accessibility

  • Trust bar stars + rating expose aria-label="4.3 von 5".
  • Option cards are <button type="button"> with aria-pressed.
  • "Beliebt" badge has aria-label="Beliebteste Wahl" for screen readers; visually a chip.
  • Consultant card uses role="note"; linger tip uses role="status".
  • Anrede radio group is role="radiogroup" with aria-checked on each.
  • All animations (slide, bounce, fade, pop) are disabled under prefers-reduced-motion: reduce.
  • Inputs use proper autoComplete tokens (name, email, tel, postal-code).

13. Integration notes

Embedding

Two embedding modes are supported, controlled by which classes get added to <html> after load:

  • ?standalone=1 when iframed → adds html.iframed-standalone, strips the funnel's own dim backdrop and transparent body.
  • No param when iframed → adds html.embedded, expands to fill the iframe.
  • Loaded directly (top frame) → centered card layout with dim backdrop.

Submission

The form currently calls submit() client-side which only flips setSubmitted(true) to show the success screen. Wire this to your real endpoint — replace the body of submit() with a fetch() POST to your CRM/lead API:

function submit() {
  setTouched({ name: true, email: true, phone: true, plz: true });
  if (!formValid) return;
  fetch('/api/leads', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ ...contact, answers })
  }).then(() => setSubmitted(true));
}

Postmessage

The funnel posts { type: 'funnel:close' } on close (when iframed) so the host page can dismiss its modal. Host listener already wired in v14/index.html.
